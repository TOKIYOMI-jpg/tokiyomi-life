# 40歳からの人生開花｜TOKIYOMI／時詠

― 今のあなたから、なりたいあなたへ。―

理想の暮らしを描き、未来を選ぶ人生シミュレーションです。

## 利用方法
GitHub Pagesの公開URLをブラウザーで開いてください。HTML単体でも動作します。
入力・プレイ記録は使用中のブラウザーに保存されます。端末・ブラウザーの変更やデータ消去で失われる場合があるため、ゲーム内の書き出し機能をご利用ください。

## この公開版
Claudeで制作したVersion 21のHTMLを書き出したものです。外部フォントはGoogle Fontsを使用します。
GPT連携は未実装です。APIキーを含みません。
人生満足度は人生の価値の採点ではありません。統計に基づく部分とゲーム上の仮定については、アプリ内「出典とルール」をご確認ください。
