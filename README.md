## 利用・データ保護

GitHub Pagesの公開URLからブラウザーで利用します。記録は基本的に利用中のブラウザーに保存され、端末変更やサイトデータ削除で失われる可能性があります。更新・機種変更前には、アプリ内「記録の保存・再開」からJSONファイルを保存し、安全な場所に保管してください。

記録の読み込みはゲームの保存形式・データ移行処理に依存します。**新バージョンで過去の記録が必ず引き継げると、検証前に案内しないでください。** 記録ファイルには個人的な内容が含まれる場合があります。

Web版はGoogle Fontsを読み込みます。現在確認したHTMLには外部AIへの送信処理やAPIキーを確認していませんが、これを網羅的なセキュリティ監査とみなさないでください。詳しくは [プライバシーポリシー](./privacy.html) をご覧ください。
