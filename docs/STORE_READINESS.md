# ストア公開準備状況
更新: 2026-10-27 / 基準: Claude Version 36.16

## 方針
日本版「40歳からの人生開花」を先に完成させる。公開Web版は変更しない。
Capacitor 8.5.3で現在のHTMLを同梱し、Android/iOSの共通資産として使う。
仮アプリID: jp.tokiyomi.lifebloom。アカウントで利用可能か確認してから初回登録する。

## 実施済み
- 依存パッケージ導入、オフライン用Web資産の生成。
- 構文チェック、保存キー維持、外部スクリプト不在、同梱資産設定のチェック。
- Google Fontsのリモート読み込みをモバイルビルドだけ除去。端末標準フォントでの目視確認はこれから。
- Android/iOS用プロジェクト生成（生成ログも確認する）。署名済みアプリではない。

## リリースを止める未完了項目
1. エンディングまでの通し検証。デモ以外にも独身・死別・低資産・高齢開始を確認。
2. WebのBlobダウンロード/FileReaderをネイティブ端末で検証し、必要なら共有・ファイル保存に対応。
3. Android戻る操作、バックグラウンド中のタイマー停止、再開時の二重進行防止。
4. 保存の失敗を現在は握りつぶしている。容量不足や破損時の通知・復旧経路が必要。
5. migrateは軸の補完が中心。v21/v35の実セーブを使い、新しい状態フィールドの互換を検証する。
6. 課金は未実装。購入済みフラグをセーブJSONやlocalStorageだけで信用しない。
7. Android/iPhone実機、画面390px、文字拡大、横画面、オフライン、読み上げの検証。
8. アイコン、実機スクリーンショット、公開ポリシーURL、サポート連絡先。
9. 開発者本人確認、契約、税務・受取情報、署名、テスト配布、審査申請。
