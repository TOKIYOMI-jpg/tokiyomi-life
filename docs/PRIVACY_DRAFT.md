# プライバシーポリシー作成メモ（未公開・申請不可）
運営者名・サポート窓口・施行日は未確定。

現行ゲームの入力と人生の記録は端末ブラウザ領域へ保存する。広告・行動解析SDKは現行コードにはない。
モバイルビルドはリモートフォントを除去している。最終アプリに入る全SDKの通信を実機で確認するまで「一切収集しない」と申告しない。
購入処理ではストアおよび採用する検証サービスが商品・取引情報を扱う。検証方式確定後に情報の種類、目的、送信先、保持・削除を記載する。
サポートへの連絡は、本人が送信した情報を取り扱う。ゲームの入力全文を自動添付しない。
書き出した記録ファイルには私的情報が含まれ得る。保存先は本人が選ぶ。
アプリ削除・端末故障・ブラウザデータ削除で記録を失う可能性がある。OSバックアップ設定も確認し、削除と復旧の説明を実装に合わせる。
端末内データの削除手順、問い合わせ先、ポリシー変更手順を用意する。
Apple App Privacy/Google Data safetyは、本番SDK込みの検証結果を基に回答する。
