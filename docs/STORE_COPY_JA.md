# 掲載原稿案（公開前に実装と照合）
アプリ名: 40歳からの人生開花
短い説明: これからの暮らしを、物語の中で選んでみよう。

今のあなたから、なりたいあなたへ。
旅、仕事、学び、趣味、人との繋がり。あなたがかなえたいことから、一つの人生が始まります。
分かれ道で迷いながら選び、その先の暮らしをピクセルアニメーションで体験する人生シミュレーションです。

・現在の年齢と、理想の暮らしから始める
・仕事、繋がり、趣味、健康、貢献、お金、学び、自由を振り返る
・希望に挑戦し、途中で選び直す
・人生の記録を残し、自分のペースで再開する

高い満足度だけが、よい人生の条件ではありません。
あなたは、本当はどうしたい？

実際の統計を使用する部分と、ゲーム上の仮定があります。将来の出来事や個人の成功・寿命を予測するものではありません。
病気、死別、葬儀などの場面を含みます。年齢区分は各ストアの質問票に基づいて設定します。
